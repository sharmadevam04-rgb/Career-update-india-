# Career Update India — starter website

A mobile-friendly static blog starter with a responsive homepage, searchable/category-filtered guide cards, six original starter articles, and policy pages.

## Files
- `index.html` — homepage
- `styles.css` — responsive styles
- `script.js` — mobile navigation, article search/filter, dynamic copyright year
- `articles/` — six starter career guides
- `privacy.html`, `disclaimer.html`, `disclosure.html`, `contact.html` — starter policy/contact pages

## Preview locally
Open `index.html` in a browser. No build step is required. Google Fonts are optional; the site falls back to system fonts if they do not load.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Create a new **public** repository named `career-update-india`.
3. Upload the *contents* of this folder to the repository root. `index.html` must be at the top level, not inside another nested folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for deployment. GitHub will show the public site URL on the Pages settings page. It commonly resembles `https://YOUR-USERNAME.github.io/career-update-india/`.

## Before monetization
- Replace or expand the starter articles with your own original, fact-checked content.
- Add a real contact method and update the contact and privacy pages.
- If you add analytics, advertising, affiliate links, or a contact form, update the privacy/disclosure pages to match what you actually use.
- Apply for an ad network only after the site meets that provider's current eligibility and policy requirements. Approval and earnings are not guaranteed.
- Do not publish unverified job notices or imply affiliation with a government body.
- For affiliate programmes, join the programme directly and use its approved links; clearly disclose qualifying links near recommendations.
- A custom domain is optional and generally costs money; the GitHub Pages URL is free.

## Limitations
This is a static website. It does not include a content management system, user accounts, backend, email sending, or a working contact form. Edit the HTML files to publish new articles, or move to a hosted blogging platform if you prefer a dashboard editor.
